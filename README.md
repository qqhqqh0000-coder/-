## 一句话介绍

文献阅读工作台用于本地管理和阅读 PDF，按 13 栏模板积累笔记，并按需使用 DeepSeek 翻译选段、生成填表草稿和思维导图。

适合需要连续阅读、回看和比较论文的人，尤其适合采用研究目的、样本、方法、暴露与结果等字段的医学与流行病学阅读。

阅读时，可以围绕三个问题留下记录：

> 这篇文章研究了什么，用了什么方法？
>
> 主要结果来自哪些原文依据？
>
> 我已经读到哪里，下一次接着看什么？

## 读完能留下什么

| 内容 | 如何继续使用 |
|---|---|
| 本地 PDF 与抽取正文 | 在文献记录中继续阅读，查看文字或版式 |
| 13 栏阅读笔记 | 在单篇或表格总览中编辑、比较 |
| 经核对的 AI 填表内容及依据 | 查看原文依据，尝试定位到 PDF 页码 |
| 选段译文与思维导图 | 在当前文献中回看，导图可复制大纲 |
| 阅读状态、位置与时间记录 | 回到上次的位置，继续阅读 |
| TSV 阅读表格 | 用 Excel 打开并继续整理；导出范围是 13 栏笔记 |

## 核心工作流

```text
导入 PDF → 检查正文 → 阅读、勾画与翻译
    → 13 栏填写草稿 → 核对原文依据 → 选择补入空白栏
    → 补充自己的思考 → 保存阅读记录 → 表格总览 / TSV 导出
```

## 核心特点

- **一篇文献一份记录**：PDF、笔记、译文、导图与阅读进度对应同一篇文章。
- **13 栏结构**：将基本信息、研究设计、结果与评价、其他补充分组，便于分次完成。
- **有依据的草稿**：自动填表先展示内容和证据，核对后只填选中的空白栏。
- **勾画篮**：默认先收集原文选段，再合并或逐条翻译；每篇文献独立保存。
- **适合续读的界面**：保留阅读位置，常用工具按需展开，译文区域随空间伸展。
- **本机恢复与导出**：自动保存、本机快照、回收站和 TSV 表格导出。

## 快速开始

普通用户使用 Windows 安装包；源码 ZIP 是开发资料，不能当成安装包直接运行。

1. 使用维护者提供的 `文献阅读工作台 Setup 0.5.5.exe`，按向导安装并启动。
2. 导入一篇带文字层的 PDF，检查正文抽取，再填写几栏笔记。
3. 需要 AI 功能时，在“设置”中填写自己的 DeepSeek API Key，然后尝试选段翻译或自动填表预览。
